# onionpi
automated-installer
OnionPi v1.0.0-beta
OnionPi is as hardware a raspberry pi and as software an access point separeted wifi that your devices can connect to stop companies and third party trackers from stealing your data.
This is the modern version of it as you can see the installer does everything for you, you just need to answer simple questions to properly install OnionPI.
This modern version does not only have newer daemons and services, it also includes Pi-Hole as your DNS, that's what blocks trackers.
OnionPi can be the most useful choice when you want privacy when using devices that you cannot control or that are monitored, or when you just feel you are.
If you are wondering why i'm bringing back to life such project is because it can be very useful and easy, whether you are privacy-oriented in your life or not, OnionPi is a great and thick wall to start protecting yourself online and so i think is a big step in privacy for beginners.
The main reason of this project is to remember everyone that privacy is a basic human right everyone should have.
